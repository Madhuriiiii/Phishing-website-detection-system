# Phishing Website Detection System

A machine learning-based web application that detects whether a website is legitimate or phishing using cybersecurity-related website features.
**live link:**   
https://phishing-website-detection-system-1-snsj.onrender.com

## Features

* Detects phishing websites using Machine Learning
* Built using Python, Flask, and Random Forest Classifier
* Web-based interface for user interaction
* Cybersecurity-focused project with real-time prediction
* Integrated with GitHub and deployed online

The project uses:

# Installation & Setup

## 1. Clone Repository

git clone https://github.com/Madhuriiiii/Phishing-website-detection-system.git

## 2. Navigate to Project Folder

cd Phishing-website-detection-system

## 3. Install Dependencies

pip install -r requirements.txt

## 4. Run Application
python app.py

## 5. Open in Browser
http://127.0.0.1:5000
